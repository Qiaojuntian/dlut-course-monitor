# DLUT 选课监测脚本

一个在浏览器本地运行的 Tampermonkey 用户脚本，用于在用户手动登录大连理工大学研究生选课系统后，监测课程列表并串行执行页面已有的选课操作。

## 功能

- 不保存账号、密码、Cookie 或验证码。
- 自动排除开发区、盘锦、非全日制和“仅限”课程。
- 支持按课程名或课程号手动排除课程。
- 同名课程互斥：任意班次选上后停止其他同名班次。
- 支持分别设置选课重试间隔和列表刷新间隔。
- 自动处理已识别的选课确认、成功、满员、类别上限与时间冲突提示。
- 调试模式下，仅在选课成功后等待用户点击“抢下一门”。

## 安装

1. 安装 Tampermonkey。
2. 下载或打开仓库根目录的 `dlut-course-watcher.user.js`。
3. 在 Tampermonkey 安装并启用脚本。
4. 用户自行登录选课系统，打开课程列表页。
5. 在右下角面板设置排除名单和间隔，点击“开始抢课”。

## 使用边界

- 只在 `https://dutgs.dlut.edu.cn/pyxx/*` 页面运行。
- 用户必须自行完成登录、验证码及任何未被识别的提示。
- 请自行确认脚本使用符合学校的选课规定；不要通过它绕过验证码、访问频率限制或其他安全机制。

## 开发

需要 Node.js 20 或更高版本。

```bash
npm run build
npm test
```

构建命令会重新生成根目录的 `dlut-course-watcher.user.js`。
