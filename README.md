# DLUT 选课监测脚本

一个在浏览器本地运行的 Tampermonkey 用户脚本。用户自行登录大连理工大学研究生选课系统后，脚本在课程列表页监测余位并串行使用页面已有的选课操作。

## 功能

- 不保存账号、密码、Cookie、验证码或登录会话。
- 自动排除开发区、盘锦、非全日制和“仅限”课程。
- 支持按课程名称或课程号手动排除课程。
- 同名课程互斥：任意一个班次确认选上后，停止同名其他班次。
- 分别设置选课重试间隔和课程列表刷新间隔。
- 自动处理已识别的选课确认、成功、满员、类别上限和时间冲突提示。
- 调试模式下，仅在确认选课成功后等待用户点击“抢下一门”。

## 安装前权限

以 Chrome 或 Edge 为例：

1. 安装并启用 Tampermonkey。
2. 打开 `chrome://extensions` 或 `edge://extensions`，找到 Tampermonkey，点击“详情”。
3. 开启“允许用户脚本”。新版 Chrome 未开启此项时，Tampermonkey 会显示“请启用允许用户脚本扩展设置”，脚本不会运行。
4. 如果通过本地文件拖拽安装脚本，额外开启“允许访问文件网址”。
5. 确认 Tampermonkey 对 `dutgs.dlut.edu.cn` 没有被浏览器限制站点访问权限。

脚本仅匹配：`https://dutgs.dlut.edu.cn/pyxx/*`。

## 安装与升级

1. 打开仓库根目录的 [dlut-course-watcher.user.js](dlut-course-watcher.user.js)。
2. 将文件拖入浏览器标签页，或在 Tampermonkey 仪表盘选择“添加新脚本”后导入其内容(直接拖动到浏览器即可)。
3. 在 Tampermonkey 安装页点击“安装”，确认 `DLUT Course Watcher` 已启用。
4. 以后更新时，使用新版 `.user.js` 重复安装步骤，Tampermonkey 会显示更新确认。
5. 刷新已打开的选课页面，使新版本生效。

## 使用方法

1. 用户自己完成学校单点登录，进入“学生网上选课”的课程列表页。
2. 等待页面右下角出现“选课监测”面板。
3. 配置排除名单和两个间隔。
4. 点击“开始抢课”。首次开始会立即尝试，不需要先点“检查名单”。

“检查名单”仅用于预览：日志会列出候选课程、已选课程组和排除原因，便于核对页面识别是否正确。

### 排除课程

每行填写一门课程，支持三种格式：

```text
2020620033
数据结构与算法
数据结构与算法 2020620033
```

课程名称必须完整填写，不能写简称。输入内容会保存到浏览器本地设置；普通刷新、重新打开选课页或浏览器后会恢复。修改排除名单时，正在运行的监测会暂停，需要重新点击“开始抢课”。

### 两个间隔

| 设置 | 含义 | 建议 |
| --- | --- | --- |
| 选课重试间隔 | 满员、冲突或未成功后，多久继续尝试下一门或同一课程组 | `1-3` 秒 |
| 列表刷新间隔 | 多久正常刷新课程表，读取别人退课后产生的余位 | `3-5` 秒 |

两个值都可设为 `1-60` 秒。脚本所有选课操作都是串行的，不会并发提交。学校提示系统忙、访问频繁或频率限制时，脚本会暂停；不要试图用更低间隔绕过限制。

### 普通模式与调试模式

| 情况 | 普通模式 | 调试模式 |
| --- | --- | --- |
| 选课确认、满员、类别上限、时间冲突 | 自动处理并继续 | 自动处理并继续 |
| 选课成功 | 自动处理并继续其他不同课程 | 自动处理后暂停，点击“抢下一门”才继续 |

调试模式只影响“选课成功”后的下一步，不会让满员或冲突停住。

## 同名课程与时间安排

脚本将规范化后的课程名称作为互斥组。同名但时间、教师、教室不同的班次，在未选上前按页面顺序轮换尝试；任一班次确认选上后，同名其他班次全部停止。

因此当前版本没有按时间段、教师或教室的优先级策略：先成功的班次会被保留。若不想抢某门课，请在排除名单中填其完整名称或课程号；这会排除该课程的所有班次。

## 已识别的提示

运行中，脚本会自动处理以下提示：

- “确定要选择该课程？”
- “选择成功”或“选课成功”
- “容纳人数已满”
- “类别课程仅限选一门，已达上限，不可选择”
- “上课时间冲突，确定仍要选择吗？”
- 页面内“选课冲突信息”遮罩弹窗中的“确定选择”

同一选课 URL 内课程行状态变化、成功后变为“退选”或人数变化，属于正常反馈，不会停止监测。实际进入另一张选课页面时，脚本会要求重新开始，避免沿用旧页面状态。

## 排障

| 现象 | 处理方式 |
| --- | --- |
| 右下角没有面板 | 检查是否启用 Tampermonkey、“允许用户脚本”及页面 URL 是否为 `/pyxx/`。刷新页面后重试。 |
| Tampermonkey 显示脚本未运行 | 检查扩展的“允许用户脚本”和站点访问权限。 |
| 脚本显示“待启动” | 点击“开始抢课”。当前已弹出的旧提示需要先由用户手动关闭一次。 |
| 出现未识别提示并暂停 | 这是一项保护措施。截图并提 issue，不要让脚本盲目点击未知提示。 |
| 选课成功却没有继续 | 检查是否开启调试模式；调试模式会在成功后等待“抢下一门”。 |

## 使用边界

- 用户必须自行完成登录、验证码及任何未被识别的提示。
- 请自行确认脚本使用符合学校的选课规定。
- 不要通过本项目绕过验证码、访问频率限制或其他安全机制。

